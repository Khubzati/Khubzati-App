# Khubzati Verified Findings

Final reconciliation date: 2026-07-26  
Evidence rule: runtime evidence overrides static inspection. A static concern without a successful runtime reproduction is not treated as a confirmed production defect.

## Evidence summary

- Real registered Express routes and an isolated test database were used for auth, payout, refund, cart, product and Stripe probes.
- Financial probes used concurrent requests or repeated signed requests, not mocked service calls.
- Flutter ran on an iPhone 17 Pro simulator for clean cold start, warm session and registered URL-scheme behavior.
- Flutter’s complete current test suite executed successfully: 60/60.
- Items without a completed production-equivalent execution are explicitly marked **Not Reproducible** and are excluded from the confirmed-blocker decision.
